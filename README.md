# EARTH & RIPPLE

An interactive physics-inspired web experience built around two simple
interactions:

> Touch the earth. Disturb the water.

DEMO : [https://nithyasrid.github.io/earth-and-ripple/](https://nithyasrid.github.io/earth-and-ripple/)

## Experiments

### 01 — Living Sand

Move through the sand and observe how the particles respond.

- Slow movement → sand follows
- Fast movement → sand scatters
- Particles naturally settle
- Mouse and touch interaction

### 02 — Liquid Glass

Interact with the water surface.

- Gentle touch → subtle ripples
- Slow movement → smaller waves
- Fast movement → stronger waves
- Multiple overlapping ripples

## Interaction

The core idea is simple:

**INPUT → PHYSICAL RESPONSE → VISUAL FEEDBACK**

No complicated controls.
No levels.
No tutorial-heavy interface.

Just interaction and reaction.
